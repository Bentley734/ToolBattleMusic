# Credits

Music compositions and performances referenced by these MIDI arrangements belong
to Tool and the respective composers of cover songs (including No Quarter and
You Lied). MIDI arrangements belong to their respective creators. This project
is not affiliated with Tool or the original composers.

Original MIDI sources: MIDIWorld and MIDIfind. SONGS.md lists the source page for
every included arrangement. Audio is synthesized from those MIDI arrangements;
no original recordings or commercial soundfont files are distributed.

The in-game ZIP asset downloader is adapted from this workspace's 1025Dex asset
manager, originally derived from KIM1025's downloader. It preserves their verified
cache installer, portable-mode handling, and native generation-specific menus.

gen1recomp provides the mod API, network fetch worker, native audio engines,
cache filesystem and UI components used by the mod.
